// the question everyone asks

Will this get me banned?

This overlay only ever does three things: reads pixels off your own screen (for the optional OCR buttons), reads your system clock (for the timers), and reads/writes a local file on your own computer (to remember what you've logged). It never touches Fortnite's process, memory, or input in any way — it's just an ordinary always-on-top window sitting over the game, the same category as a stopwatch app or OBS.

  • No process injection. Never reads or writes Fortnite's memory.
  • No input simulation. Never sends clicks or keystrokes into the game.
  • Screen + clock only. Everything it "sees" is optional, manual, and on-screen only.
